# CRM Explorer

Projeto:

Programa que irá importar pastas com arquivos .crm(Arquivos com backgroud de jogos, que normalmente são editados em aplicações como AGR Editor).

A interface deve ser limpa, simples e intuitiva, com as única funções sendo:

Importar pasta: Abre o diretório, importa os arquivos .crm;
Mostra uma tela com as imagens contidas nos arquivos, como um arquivo .crm pode ter mais de uma imagem, caso houver, serão organizadas como sub-arquivos, por exemplo:

room1.crm
- Imagem1
room2.crm
-Imagem1
room3.crm
- Imagem1
-Imagem2

A interface permite uma visualização geral em grade, com a miniaturas, ou uma visão em estilo "portifólio", com uma imagem centralizada, e podendo mover para frente e para trás, passando para a próxima imagem ou anterior na visualização;
